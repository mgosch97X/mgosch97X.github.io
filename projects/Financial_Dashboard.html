📈 Financial Market Dashboard — Multi-Sector Analysis

Goal: Analyse stock performance across 5 sectors using 3 years of daily market data to identify price trends, sector returns, seasonal patterns, and volume anomalies.

Tools & Process

  • Python (yfinance) — Pulled 3 years of daily stock data for 10 companies across 5 sectors.
  • SQL (SQLite) — Stored data in a relational database and ran all analysis using window functions, CTEs, and aggregations.
  • Tableau Public — Built an interactive 4-sheet dashboard with filters for exploring individual stocks and sectors.

Key Insights

  • Finance was the top-performing sector, with Goldman Sachs returning 175% and JPMorgan 158%, far outpacing all other sectors.
  • Technology delivered strong but uneven gains, with AAPL up 122% and MSFT up 108%, while in Healthcare, Pfizer dropped 42% — the only stock with a negative return.
  • March was consistently the strongest month, with March 2025 delivering exceptional returns — AAPL at 23%, GS at 18%, JPM at 16%.
  • Volume anomalies spiked in late 2024 and early 2025, with ratios reaching 5–6x the 20-day average, suggesting increased market activity.

SQL Highlights

These queries demonstrate window functions, CTEs, and conditional aggregation applied to real financial data to generate actionable insights.

Moving Averages

Calculates 30-day and 90-day moving averages to identify price trends and momentum shifts.

SELECT
    ticker, sector, date, close,
    AVG(close) OVER (
        PARTITION BY ticker
        ORDER BY date
        ROWS BETWEEN 29 PRECEDING AND CURRENT ROW
    ) AS ma_30,
    AVG(close) OVER (
        PARTITION BY ticker
        ORDER BY date
        ROWS BETWEEN 89 PRECEDING AND CURRENT ROW
    ) AS ma_90
FROM stock_prices
ORDER BY ticker, date

Volume Anomaly Detection

Identifies trading days where volume exceeded 2x the 20-day average, flagging unusual market activity.

WITH vol_avg AS (
    SELECT
        ticker, date, volume, close,
        AVG(volume) OVER (
            PARTITION BY ticker
            ORDER BY date
            ROWS BETWEEN 19 PRECEDING AND CURRENT ROW
        ) AS avg_volume_20d
    FROM stock_prices
)
SELECT
    ticker, date, volume,
    CAST(avg_volume_20d AS INTEGER) AS avg_volume_20d,
    ROUND(CAST(volume AS REAL) / avg_volume_20d, 2) AS volume_ratio
FROM vol_avg
WHERE volume > avg_volume_20d * 2
ORDER BY volume_ratio DESC
